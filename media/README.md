# Media

Ten images for the submission. Everything here was produced on the live site.

The four paintings were painted through the WebMCP tools, one `paint` call per
part, each landing on paper the previous call left wet. No image model touched
any of them.

| File | What it is |
| --- | --- |
| `01-evening-river.png` | The *Evening river* score, 22 marks |
| `02-the-fox.png` | *The fox*, 22 marks |
| `03-deep-water.png` | *Deep water*, 19 marks |
| `04-three-poppies.png` | *Three poppies*, 18 marks, written for the submission |
| `05-the-duet-board.png` | A duet six parts in, one part in the human's hand, its guides on the paper |
| `06-a-mark-taken-apart.png` | A mark selected: its author, pigment, brush, water and literal SVG path |
| `07-the-tool-surface.png` | The live tool surface, grouped, with one tool mid-call |
| `08-replay.png` | The painting replaying, mark by mark, in the order they were made |
| `09-the-log.png` | Who made what, in order |
| `10-the-scores.png` | Choosing a score |
